# RAL MASTER PRO

Самостоятельное Android-приложение для работы с цветами и пользовательскими рецептами колеровки.

## Текущие возможности

- Каталог RAL Classic: 216 записей, поиск по коду, названию и HEX.
- Экранное сравнение оттенков и избранное.
- Расчёт расхода компонентов сохранённой рецептуры по объёму.
- Редактор собственных рецептур по материалу, системе и базе.
- Импорт и экспорт пользовательских рецептур в JSON.
- Библиотека пользовательских пигментов.
- Экспериментальный RAL Design Lab с расчётной CIELAB-визуализацией.

## Важные ограничения

Цветовые значения HEX/RGB являются приближёнными экранными представлениями. Они не заменяют физические образцы RAL и не являются колеровочными формулами. Рецептуры должны быть привязаны к конкретному производителю, серии, базе, материалу и колорантам. Приложение не подставляет выдуманные заводские дозировки.

RAL Design Lab вычисляет цвет по введённым H/L/C параметрам; это не официальный каталог кодов RAL Design.

## Источник данных RAL Classic

Палитра сформирована из файла `ral_classic.csv` проекта [JohannesVoigt/ral-color-converter](https://github.com/JohannesVoigt/ral-color-converter), 216 строк. Исходный проект распространяется по MIT License; уведомление об авторских правах: Copyright (c) 2024 brohannes.

Данные предназначены для экранного ориентирования. Для ответственных работ используйте физический веер RAL и проверяйте цвет при нужном освещении.
