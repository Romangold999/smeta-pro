# PLAN MASTER 3D — полная спецификация и контрольный список

Этот документ — единый источник требований к PLAN MASTER 3D. Перед добавлением функций сверяться с ним, чтобы не терять согласованные требования и не добавлять исключённые инструменты.

## 1. Границы проекта и обязательные правила

- [x] Самостоятельное Android-приложение, отдельная ветка `plan-master-3d`, пакет `ru.planmaster3d.app`.
- [x] Не передавать данные в Smeta Pro; не менять основной проект Smeta Pro и RAL MASTER PRO.
- [ ] Рабочий офлайн-режим с сохранением нескольких объектов и последующим редактированием.
- [ ] Все введённые измерения и сметные данные должны сохраняться между запусками.
- [ ] Изменение геометрии автоматически обновляет связанные площади, объёмы, расход материалов и смету.
- [ ] Не подменять точные измерения догадками; не исправлять невязку молча и не превращать произвольную комнату в прямоугольник.
- [ ] Разделять исходные замеры, вычисленную геометрию и ручные корректировки; показывать пользователю величину расхождения.
- [ ] Минимизировать прокрутку: основные разделы открывать отдельными экранами/панелями; интерфейс должен быть удобен на телефоне.
- [ ] Не собирать новый APK на каждую мелкую правку; сборка после завершённого этапа и проверки.

## 2. Объекты, помещения и обмеры

- [ ] Несколько объектов/проектов, несколько помещений в каждом объекте.
- [ ] Создание помещения по длинам стен, углам, диагоналям и толщине стен.
- [ ] Произвольные контуры: ломаные, косые и непрямоугольные стены.
- [ ] Разные высоты и толщины отдельных стен/сегментов.
- [ ] Ниши, выступы, колонны и другие сложные элементы.
- [ ] Проверка замыкания контура (невязки), самопересечений и некорректных данных.
- [ ] Отдельное хранение исходных измеренных векторов/длин и расчётного контура.
- [ ] Режим точного обмера; режим корректировки с показом вариантов; ручная корректировка.
- [ ] Не менять автоматически исходные размеры при закрытии контура.
- [ ] Рисование пальцем как дополнительный быстрый способ, не вместо точного ввода размеров.

## 3. Инструмент «Линейка»

- [ ] Расстояние между двумя точками.
- [ ] Последовательная ломаная с суммарной длиной.
- [ ] Площадь произвольной области.
- [ ] Импорт фотографии, изображения или PDF-чертежа.
- [ ] Калибровка масштаба по известному размеру/отрезку.
- [ ] Размерные подписи на плане с сохранением.
- [ ] Привязка измерений к стенам, углам и проёмам.
- [ ] Не определять неизвестные размеры автоматически без калибровки/основания.

## 4. Полноценный 2D-план

- [ ] Редактируемый план помещения, а не только статичная схема.
- [ ] Добавление, перемещение и изменение стен/вершин с точными числовыми значениями.
- [ ] Размерные линии, диагонали, углы и подписи.
- [ ] Двери, окна, проёмы, откосы и подоконники.
- [ ] Ниши, выступы, колонны и неодинаковые высоты.
- [ ] Выбор элементов, редактирование свойств и отмена/повтор действий.
- [ ] Печать/экспорт плана с размерами в PDF.

## 5. Настоящая 3D-модель

- [ ] Генерация модели из текущей геометрии 2D.
- [ ] Высота и толщина стен, пол и потолок.
- [ ] Окна, двери, проёмы, откосы, ниши, выступы и колонны.
- [ ] Вращение, масштабирование и перемещение камеры.
- [ ] Скрытие стен/режим разреза для просмотра внутренней части.
- [ ] Реальный интерактивный 3D-рендер, не статичная картинка.
- [ ] Изменения 2D-геометрии обновляют 3D-модель.

## 6. Автоматические площади и ведомости

- [ ] Периметр, площадь пола, стен и потолка.
- [ ] Раздельная площадь каждой стены, включая стены разной высоты.
- [ ] Площадь окон и дверей отдельно.
- [ ] Чистая площадь стен с настраиваемым вычитанием проёмов.
- [ ] Откосы и подоконники рассчитываются отдельно и могут включаться/исключаться.
- [ ] Учет внутренних/наружных сторон перегородок по настройке.
- [ ] Корректный учёт ниш, колонн и выступов.
- [ ] Ведомость по каждому помещению и сводная ведомость по объекту.
- [ ] Все результаты пересчитываются после изменения геометрии.

## 7. Смета и прайс-листы

### Совместимость с каталогом Smeta Pro
- [x] Исходный каталог Smeta Pro перенесён в проект.
- [ ] Сохранить без изменений исходные названия, стартовые цены, единицы измерения, категории и признак «от» для всех совпадающих позиций.
- [ ] Не округлять и не переоценивать перенесённые пользовательские цены.
- [ ] Не дублировать позиции, которые уже присутствуют в каталоге Smeta Pro.

### Расширение каталога

- [ ] Малярные работы.
- [ ] Декоративная отделка: венецианская штукатурка, замша/нубук, бетон, травертин, микроцемент, лаки и сопутствующая подготовка.
- [ ] Обои: разные типы, подготовка основания, поклейка и демонтаж.
- [ ] Электромонтажные работы — расширить без повторения существующих позиций.
- [ ] Полы: ламинат, паркет, наливные покрытия и сопутствующие операции.
- [ ] Потолки, перегородки, кладка, двери, демонтаж/монтаж и прочие отсутствующие виды работ.
- [ ] Новые цены — стартовые ориентировочные, редактируемые, явно помеченные как ориентировочные; где уместно — «от».
- [ ] Раздельные категории работ и материалов.
- [ ] Пользовательские позиции с названием, единицей, категорией и ценой.

### Работа со сметой и прайсом
- [ ] Редактирование количества, единицы, цены и описания каждой позиции.
- [ ] Несколько прайс-листов и версии прайса; сохранение, переключение и возврат к старой версии.
- [ ] Обновление цен не должно менять уже зафиксированную историческую смету без подтверждения.
- [ ] Автозаполнение объёмов из обмеров с возможностью ручной корректировки.
- [ ] Разные расценки по помещениям.
- [ ] Коэффициенты сложности и высоты, скидки и наценки.
- [ ] Запас материалов в процентах/количестве.
- [ ] Варианты бюджета: эконом, стандарт, премиум.
- [ ] Плановая и фактическая стоимость, сравнение и журнал изменений.
- [ ] Смета отдельно по помещениям и сводная по объекту.

## 14. Демонтаж и вывоз строительного мусора

### Выбор участков демонтажа на плане
- [ ] Режим/слой «Демонтаж» в 2D-плане: пользователь выбирает конкретные стены, участки стен, перегородки, покрытия или отдельные области.
- [ ] Возможность отметить не всю стену, а заданный отрезок/часть поверхности с точными границами и размерами.
- [ ] Для каждого участка задаются тип конструкции/материала, длина, высота, толщина и глубина демонтажа; неизвестные характеристики можно указать вручную.
- [ ] Отдельные виды работ: демонтаж перегородки целиком или частично, штукатурки/шпаклёвки/плитки/стяжки/напольного покрытия/обшивки и других слоёв.
- [ ] Слои отделки и конструктивные элементы учитывать раздельно, чтобы не задваивать объёмы.
- [ ] На плане визуально различать существующие конструкции, выбранные под демонтаж и сохраняемые участки.
- [ ] Для каждого выбранного элемента формировать отдельную позицию/объём в ведомости демонтажа и смете.

### Расчёт объёма, массы и мешков
- [ ] Рассчитывать площадь, объём и массу демонтируемого материала по геометрии и выбранной/заданной плотности.
- [ ] Для многослойной конструкции рассчитывать каждый слой отдельно.
- [ ] Предусмотреть справочник плотности материалов с возможностью редактирования и ручного ввода; показывать, какие значения взяты из справочника, а какие введены пользователем.
- [ ] Рассчитывать ориентировочную массу строительного мусора с учётом коэффициента разрыхления/изменения объёма после демонтажа.
- [ ] Рассчитывать количество мешков по выбранной вместимости/допустимой массе мешка и выбранному коэффициенту заполнения.
- [ ] Не превышать заданную пользователем допустимую массу на мешок; показывать расчётное число мешков и общий вес отдельно.
- [ ] Для мешков разного литража/грузоподъёмности давать выбор параметров; литраж не считать равным весу без плотности/коэффициента.
- [ ] Показывать расчёт как оценку, если плотность, состав или влажность материала неизвестны; позволять корректировать коэффициенты.
- [ ] Формировать ведомость мусора: материал, исходный объём, расчётный вес, разрыхлённый объём, тип мешка, количество мешков и суммарный вес.
- [ ] Добавлять в смету демонтаж, упаковку, вынос/погрузку и вывоз раздельными позициями, чтобы пользователь мог включать только нужные услуги.

## 15. Новые перегородки и конструкции

### Размещение на плане
- [ ] Отдельный режим/слой «Новые перегородки».
- [ ] Пользователь рисует/выбирает линию будущей перегородки на плане, задаёт начало/конец, длину, высоту и привязку к существующим стенам.
- [ ] Поддержать ломаные участки и проёмы в новой перегородке.
- [ ] Новая перегородка отображается на плане и в 3D отдельным типом/цветом, отличимым от существующих стен и демонтажа.
- [ ] После построения перегородки геометрия помещений обновляется: площади, периметры, поверхности стен и объёмы связанных работ пересчитываются.
- [ ] Поддержать сметный расчёт по фактически построенной на плане конструкции, а не только по вручную введённому общему количеству.

### Выбор конструкции и материалов
- [ ] Для каждой перегородки выбрать тип конструкции: газобетон/газосиликатный блок, пазогребневая плита, кирпич, ГКЛ по металлическому каркасу, другие пользовательские типы.
- [ ] Для блочных материалов выбирать толщину из вариантов (например, 100, 150 мм и другие доступные размеры), формат блока, расход блоков на м²/м³ и плотность/марку при наличии данных.
- [ ] Возможность добавлять собственные размеры блоков, толщину и характеристики материала.
- [ ] Для ГКЛ-конструкции выбирать число слоёв обшивки с каждой стороны (например, один или два), тип и толщину листа, обшивку одной/двух сторон.
- [ ] Для ГКЛ выбирать наличие или отсутствие шумоизоляции, тип/толщину заполнения и его характеристики.
- [ ] Для каркасных перегородок выбирать тип/ширину профиля, направляющие и стойки, схему усилений, перемычки и обрамление проёмов.
- [ ] Для всех типов задавать толщину готовой перегородки, высоту, длину, проёмы и особенности примыканий.
- [ ] Характеристики материалов (плотность, размеры, масса, расход, упаковка) должны быть редактируемыми и сохраняться в пользовательском справочнике.

### Расчёт материалов и каркаса
- [ ] Газобетон/газосиликат: площадь и объём кладки за вычетом проёмов, количество блоков по выбранному формату, раствор/клей, запас и масса.
- [ ] ГКЛ: количество листов по размерам, числу слоёв и обшиваемых сторон, раскладка листов с учётом проёмов и запаса.
- [ ] Каркас: рассчитывать направляющие по полу/потолку и примыканиям; стойки по выбранному шагу 400 или 600 мм, с возможностью задать другой шаг.
- [ ] Показывать точное расчётное количество стоек, направляющих, перемычек и усилений, а также суммарную длину профиля и количество хлыстов стандартной длины.
- [ ] Учитывать дополнительные стойки у дверных/оконных проёмов, углов, стыков листов и мест усиления; правила раскладки должны быть видимыми и редактируемыми.
