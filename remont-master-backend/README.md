# RemontMaster backend (isolated)

Отдельная серверная часть для сайта «РемонтМастер». Не связана с Cloudflare Pages проектом smeta-pro и не меняет существующий сайт до отдельного подключения.

## Состав
- Cloudflare Worker: JSON API, проверка администратора, загрузка изображений.
- D1: содержимое сайта, каталог работ, заявки, метаданные изображений.
- R2: оригиналы загруженных изображений.
- public/admin/index.html: мобильная панель владельца.
- migrations/0001_initial.sql: схема базы.

## Текущие ограничения
1. Публичный сайт пока не подключён к API. Его HTML, дизайн, калькулятор и локальные сохранения не менялись.
2. Каталог и содержимое доступны через API после развёртывания, но пока не синхронизированы с текущим интерфейсом сайта.
3. Пароль и секрет сессии задаются только как Worker secrets; не хранить их в Git.
4. Перед production нужно добавить Turnstile/антиспам, резервное копирование D1 и проверку доступа к панели.
5. На первом этапе универсальный редактор содержимого использует JSON; далее его нужно заменить удобными полями и таблицами с предпросмотром.

## Развёртывание в отдельном Cloudflare-проекте
1. Создать Worker remont-master-backend.
2. Создать D1 remont-master-db и применить migrations/0001_initial.sql.
3. Создать R2 bucket remont-master-media.
4. Вставить реальный D1 database ID в wrangler.toml.
5. Добавить secrets ADMIN_PASSWORD и SESSION_SECRET (случайная строка минимум 32 байта).
6. Проверить ALLOWED_ORIGIN: https://romangold999.github.io.
7. Развернуть Worker и проверить /api/health, /admin/, авторизацию и загрузку изображения.

Не вставляйте API token, пароль или SESSION_SECRET в переписку, исходники либо коммиты.
