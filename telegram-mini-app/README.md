# Смета Pro — Telegram Mini App

Отдельная веб-версия Android-приложения из `main`. Исходный Android-код не изменяется.

## Реализовано в первой версии
- Пять исходных разделов: Главная, Смета, Прайс, Проекты, Настройки.
- Перенесён встроенный каталог работ и исходные цены.
- Добавление, редактирование и удаление строк сметы; расчёт итоговой суммы.
- Несколько проектов, редактирование прайса и создание версий прайса.
- Экспорт PDF через системную печать браузера, XLSX, отправка/копирование текста.
- Адаптивный интерфейс и подключение Telegram Web Apps SDK.
- Никакие данные не сохраняются в боте, браузере или на сервере: сметы и изменения прайса существуют только в оперативной памяти до закрытия Mini App.\n- Экспорт PDF, XLSX и TXT скачивает файлы на устройство пользователя.

## Запуск
Разместить содержимое папки на HTTPS-хостинге и указать URL в настройках Telegram-бота как Web App URL. Для скачивания PDF и XLSX требуется доступ к CDN.

## Важно
Это начальный перенос интерфейса и функций. По требованию владельца приложение ничего не сохраняет: при закрытии Mini App данные сеанса пропадают. Пользователь сохраняет только экспортированные файлы на своё устройство.
