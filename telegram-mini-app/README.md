# Смета Pro — Telegram Mini App

Отдельная веб-версия Android-приложения из `main`. Исходный Android-код не изменяется.

## Реализовано в первой версии
- Пять исходных разделов: Главная, Смета, Прайс, Проекты, Настройки.
- Перенесён встроенный каталог работ и исходные цены.
- Добавление, редактирование и удаление строк сметы; расчёт итоговой суммы.
- Несколько проектов, редактирование прайса и создание версий прайса.
- Экспорт PDF через системную печать браузера, XLSX, отправка/копирование текста.
- Адаптивный интерфейс и подключение Telegram Web Apps SDK.
- Данные изолированы от Android-приложения и пока хранятся локально в хранилище браузера Telegram.

## Запуск
Разместить содержимое папки на HTTPS-хостинге и указать URL в настройках Telegram-бота как Web App URL. Для работы XLSX требуется доступ к CDN.

## Важно
Это начальный перенос интерфейса и функций. В исходном Android-приложении данные сохраняются локально на устройстве; здесь они сохраняются отдельно в Telegram WebView. Для синхронизации между устройствами понадобится отдельный сервер и база данных — это не включено, поскольку исходник не содержит серверной синхронизации.
